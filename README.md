### 1. grid로 칸이 나뉘지 않았다

**문제**: CSS grid로 게시글을 네 칸으로 나누려 했는데
계속 한 칸으로만 나왔다.

**원인**: `<li>` 바깥이나 `<ol>` 전체를 `<div>`로 감쌌다.
grid는 자기 바로 아래 자식만 칸에 배치하는데,
`<li>` 안의 글자는 태그가 아니라서 자식으로 인식되지 않았다.

**해결**: `<li>` 안에서 번호·제목·작성자·추천수를 각각
`<span>`으로 감싸 자식 네 개를 만들었다.
그제서야 grid가 네 칸으로 나눴다.


#2. 자유게시판

JavaScript로 만든 게시판 목록 화면입니다.
웹 개발 학습 과정에서 만든 첫 프로젝트입니다.

## 사용 기술

- HTML
- CSS (Grid)
- JavaScript

## 기능

- 게시글 데이터를 배열에 담고 반복문으로 화면에 자동 생성
- 추천 버튼 클릭 시 추천수 증가 후 화면 재렌더링
- CSS Grid로 번호·제목·작성자·추천수 정렬

## 만들면서 막혔던 것

### document.write로는 화면을 다시 그릴 수 없었다

**문제**
게시글 목록까지는 `document.write`로 잘 출력됐다.
그런데 추천 버튼을 붙이려고 보니,
버튼을 눌렀을 때 바뀐 숫자로 화면을 다시 그릴 방법이 없었다.

**원인**
`document.write`는 페이지 로딩이 끝난 뒤에 호출하면
문서 전체를 지우고 새로 쓴다.
버튼을 한 번 누르면 제목도 머리글도 전부 사라지고
새로 쓴 내용만 남게 되는 구조였다.

또 `document.write`는 스크립트가 놓인 위치에 출력하는 방식이라,
원하는 요소만 골라서 바꿀 수도 없었다.
